# Design artifacts

This directory will hold the approved design baseline and its addenda. It is empty of design
artifacts today.

- **Issue #2 — approved mockup import.** Imports the approved baseline mockup, the decision
  inventory, the provisional palette table, and reference screenshots, so the approved design is
  reproducible from the repository alone. The baseline is immutable except by decision; addenda
  extend it, never edit it.
- **Issue #15 — mockup addendum.** Adds the corrective and missing states: security-chip states,
  keyboard-focused rail, rail modes, workspace monograms, bottom utility cluster, Ctrl+L state,
  command result, inline error, solid/reduced-transparency mode (Architecture Pack v1.1 Section 2),
  the extension-action frames (Addendum v1.2 §7, badge-corrected), and the identity, permission,
  tracking-protection, page-action and container frames (Patch v1.2.1 §5), with their spike-gated
  captions.

Known input question for Issue #2, recorded here rather than resolved: the approved mockup file
references a sibling `support.js` and a remote web font. Whether those are imported, vendored, or
recorded as external context is part of #2's scope.

Design values marked *(provisional)* in the architecture documents stay provisional here; final
opacity numbers are owned by the DMS Token Mapping RFC ([`docs/rfcs/`](../rfcs/README.md)).
